# RoadTrip Couple

Aplicación web progresiva (PWA) para registrar y puntuar viajes en pareja.

## Probar
Abre `index.html` en un navegador para probar la app. Para instalarla como aplicación y habilitar el modo sin conexión, publícala en un hosting con HTTPS (por ejemplo, GitHub Pages, Netlify o Vercel).

## Instalar en iPhone
1. Abre la dirección HTTPS publicada en Safari.
2. Pulsa Compartir.
3. Elige «Añadir a pantalla de inicio».

## Datos
Los viajes se guardan en el almacenamiento local del navegador. Usa «Diario > Exportar copia» para guardar una copia JSON. No hay sincronización entre dispositivos en esta primera versión.

## Archivos
- `index.html`: aplicación.
- `manifest.webmanifest`: configuración instalable.
- `sw.js`: caché básica para funcionamiento sin conexión.
